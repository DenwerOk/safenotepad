# Safe NotePad
A simple notepad that allows to store and share rich text notes encrypted with a password 

## The problem
Sometimes it is necessary to share a simple text information by email or messenger that should be protected from external eyes.

## The solution
Safe NotePad provides a new file format: sfnote. This file format simply means - a text file encrypted and protected with a password.
It's using a combination of strong cryptographic algorithms PBKDF2 an AES 256 to password protect files and holds a strong resistance against brute-force attacks and other possible intrusions.
All password protected files stay local and the app is not using any external connections to decrypt or otherwise access the content of the files.

## Features
1. Saving password protected text files
2. Ability to change and assign a new password
3. Strong industry standard security algorithms
4. Designed to be used on Windows
